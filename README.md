# CreditWise Loan System


CreditWise Loan System is an end-to-end supervised machine learning project developed to predict whether a loan application should be approved or rejected based on an applicant's financial, employment, demographic, and credit-related information. The project aims to assist financial institutions in making faster and more consistent loan approval decisions by identifying patterns from historical loan application data using classification algorithms.

The project follows a complete machine learning pipeline, including data preprocessing, missing value handling, exploratory data analysis (EDA), feature encoding, feature scaling, feature engineering, model training, and performance evaluation. Multiple classification models, including Logistic Regression, K-Nearest Neighbors (KNN), and Gaussian Naive Bayes, are implemented and evaluated using metrics such as Precision, Recall, and F1-Score to determine the most effective model for loan approval prediction.
